# 架构与技术选型（ImageOracle）

> 数值口径（变换矩阵 / ICC 校验项 / 帧单位 / gray 条件 / 退出码）**只在 `data/README.md` §8 定义一次**，本文件不复述数值。

## 一、定位与技术选型

纯本地 CLI：**只读字节** → 输出判决 + `evidence`。不解码像素、不做颜色变换、不联网、不写回源文件。

| 项 | 选型 | 理由 |
|---|---|---|
| 语言 | Python **3.12**（`requires-python = ">=3.12"`；2026-10-28 二次迭代抬 floor，3.10/3.11 已 EOL） | `struct` 精确控字节；`zlib.crc32` 是标准库里的 CRC-32；无第三方依赖 → 离线可审计、CI 无需装包 |
| 打包 | `pyproject.toml` + `setuptools`，`src/` 布局 | 唯一来源：版本号只写 `src/imageoracle/__init__.py` 与 `pyproject.toml` **两处**，由测试断言一致 |
| CLI | 标准库 `argparse`，子命令 `orientation` / `double-rotate` / `color` / `container` / `consumers` | 零依赖；统一 `--json` 出机读，默认出人读 |
| 测试 | 标准库 `unittest` 驱动（`py -3.12 -m unittest discover`），**不引入 pytest** | 判定路径零第三方依赖这条要能在"无网容器"里自证；CI 直接跑 |
| 生成器 | `fixtures/gen_*.py`，纯字节构造 | **本机没有 exiftool/jpegtran/sharp**（2026-10-27 实测）；且 skill 纪律要求"真值的字节不能依赖跑生成器那台机器的工具链版本" |

**为什么不引入 Pillow / pytest / jsonschema**：任何第三方 import 都会让"离线、零网络、无安装步骤"这条
可证伪性下降，也会在 CI 的 no-network job 里引入安装面。判定所需的一切（TIFF IFD、JPEG 段、PNG chunk、
ICC 头、CRC、GIF 块、RIFF 块）都是**定长字节 + 偏移**，标准库足够。

## 二、分层

四层，依赖**单向向下**，每层只依赖下一层：

```
┌──────────────────────────────────────────────────────────────┐
│ 呈现层  report/       人读表（左） + 机读 JSON（右），同源渲染  │  ← 零判定
├──────────────────────────────────────────────────────────────┤
│ 判决层  modules/      orientation / double_rotate / color /    │  ← 出 finding + evidence
│                       container / consumers                    │
├──────────────────────────────────────────────────────────────┤
│ 语义层  model/        统一中间表示：Container / Chunk /        │
│                       Segment / Ifd / IccHeader / Frame        │  ← 只描述结构，不判对错
├──────────────────────────────────────────────────────────────┤
│ 容器层  readers/      jpeg / tiff / png / webp / gif           │  ← 只切片，不解释
└──────────────────────────────────────────────────────────────┘
        specs/  规范条款 ID + 原文片段（evidence 的唯一来源）
```

**分层铁律（AST 守门，测试断言）**：

1. `readers/` **禁止** import `modules/`（容器层不得知道判决语义）。
2. `modules/` **禁止** import `report/`（判定不依赖渲染——skill「判定与呈现分家」）。
3. `report/` **禁止** import `readers/`（渲染只吃 `model/` + finding）。
4. 全仓库**禁止** import 任何第三方包（`sys.stdlib_module_names` 之外一律不在允许集）。
5. 全仓库**禁止** `socket` / `urllib` / `http` / `requests`（零网络是可断言的红线，不是承诺）。

## 三、字节读取边界（只读硬约束的落地）

| 约束 | 落地方式 | 判据 |
|---|---|---|
| 不写回源文件 | 只以 `"rb"` 打开；写操作全部走 `--out` 指定的目录或 stdout | 测试：跑完全部子命令后源文件 `sha256` 不变 + `mtime` 不变 |
| 不解码像素 | `readers/` 只返回 chunk/segment 的**偏移、长度、类型字节**，不产出像素数组；IDAT/fdAT/图像数据一律不 `zlib.decompress`（`iCCP` 首期也不解压） | 测试：AST 守门禁止 `zlib.decompress` 出现在 `readers/` 与 `modules/`（`crc32` 允许） |
| 零网络 | 不 import 网络模块；无 `subprocess` 调用 | AST 守门 + no-network CI job |
| 不读时钟 | 报告头的时间戳由**调用方传入**（`--generated-at`），默认取 `SOURCE_DATE_EPOCH` 或固定串；核心模块禁止 `datetime.now`/`time.time` | AST 守门（定位到函数体，不数文本出现次数） |
| 确定性 | 输出 JSON `sort_keys=True`、`ensure_ascii=False`、固定 `separators`；所有集合先排序；**不出现浮点**（帧时长用整数 ms） | 双跑逐字节相等测试 |

## 四、统一中间表示（语义层）

所有容器归一成同一组结构，判定层只读它们——**"跨容器同一件事"由此只写一次**：

```
Container
├── kind: "jpeg" | "tiff" | "png" | "webp" | "gif"
├── size: int                     # 文件字节数
├── chunks: [Chunk]               # png/webp/gif 的块；jpeg 的段也放这里（type 用段标记名）
├── segments: [Segment]           # jpeg 专用：marker + offset + length
├── image_info: ImageInfo         # 宽/高/位深/color_type（从头部字段读，不解码）
├── exif: [ExifBlock]             # 0..n 个（JPEG APP1 / PNG eXIf / WebP EXIF / TIFF 本身）
├── xmp: [XmpBlock]               # 0..n 个
├── icc: IccRef | None            # 指向载体（JPEG APP2 多段 / PNG iCCP / WebP ICCP / TIFF 34675）
└── frames: [Frame]               # 动画帧时序（gif / apng / webp anim / avif→not-in-band）
```

`ExifBlock` → `[Ifd]`（ifd0/ifd1/…）→ `[IfdEntry]`（tag / type / count / value_offset / value_bytes）。
**值读取必须按 TIFF 头声明的字节序**（`II` = LE / `MM` = BE），不得固定小端——这是 `data/README` §1.1 的核对点。

## 五、构建与发布形态

- `pyproject.toml`：`[project.scripts] imageoracle = "imageoracle.cli:main"`；无 `dependencies`。
- 本地跑：`py -3.12 -m imageoracle --help`（无需安装）；安装态：`py -3.12 -m pip install -e .`。
- 发布附件：**手工源码包**（`git archive --format=tar.gz --prefix=imageoracle-<ver>/ <tag>`），
  口径与复核步骤见 `plan/05` §三。GitHub 自动生成的 Source code 包 sha256 本地复算不出来，不用。
- CI：`.github/workflows/ci.yml`，矩阵 `3.12` / `3.13` × `ubuntu-latest` / `windows-latest`；
  额外一个 `offline` job 用嵌套 `docker run --network none`（**不能**用 job 容器 + `--network none`，那是 docker 互斥选项）。
