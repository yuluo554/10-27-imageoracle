## 四、决策记录（追加，主表见 `plan/00`）

| # | 决策 | 结论 | 理由 |
|---|---|---|---|
| D11 | 测试框架 | 标准库 `unittest`，**不引入 pytest** | 零依赖可证伪（无网容器里能跑通即证明"零第三方 import"） |
| D12 | 版本号真源 | `src/imageoracle/__init__.py` + `pyproject.toml` 两处，测试断言相同 | 单一来源在纯 stdlib 下没有构建期注入；两处 + 一条测试等价 |
| D13 | 发布附件 | 手工源码包（`git archive --format=tar.gz`） | GitHub 自动 Source code 包的 sha256 本地复算不出来 |
| D14 | CI 矩阵 | Python 3.10 / 3.12 × ubuntu / windows + 一个 `offline` job | 覆盖最低支持版本与实际开发版本；offline job 证零网络 |
| D15 | 报告 `generated_at` 默认值 | `"1970-01-01T00:00:00Z"` | 确定性优先；真实时间由调用方传入 |
| D16 | 规范条款 ID 体系 | `EXIF-TAG274` / `ICC-HEAD` / `PNG3-T7` / `PNG3-CRC` / `APNG-SEQ` / `WEBP-ANMF` / `GIF89A-GCE` | evidence.spec 必须可查；ID 在 `specs/` 里逐条对应原文 |
